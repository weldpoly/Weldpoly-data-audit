# Weldpoly App — Data Audit

This repository contains all machine data and calculation formulas used in the **Weldpoly** app.

## How to review and suggest changes

1. Open [`machines.csv`](machines.csv) — click the **pencil icon ✏️** (top right) to edit
2. Update any values that need correcting (e.g. cylinder area for a machine)
3. Scroll down → click **"Propose changes"** → **"Create pull request"**
4. The development team will review the diff and update the app

> You can also open an **Issue** (tab at the top) to leave comments or questions about specific values.

## Files in this repo

| File | What it contains |
|---|---|
| [`machines.csv`](machines.csv) | All machine names, cylinder areas, OD ranges |
| [`FORMULAS.md`](FORMULAS.md) | All calculation formulas used in the app |
| [`AUDIT_CHECKLIST.md`](AUDIT_CHECKLIST.md) | What needs to be verified by Weldpoly engineers |
